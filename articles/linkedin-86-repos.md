People ask why I have 86 repositories.

The answer is simple: I ship constantly.

Every idea becomes a repo. Every experiment becomes a commit. Every tool I build for myself gets pushed to GitLab or GitHub so someone else can use it.

Each repo represents a decision: build something, ship it, learn from it, move on.

Not every project is successful. Many are unfinished. Some are just experiments that taught me one thing and were done.

That's the point.

The 86 repos are not a portfolio. They're a log of a builder in motion. Each one is a snapshot of what I was thinking about, what problem I was trying to solve, what tool I needed in that moment.

If you're a developer reading this: stop optimizing. Start shipping. Create the repo. Write the README. Push the code.

Someone will find it and use it. That's how open source works. That's how I learned.

The next repo is always the most important one.
